# Aether design system

The Aether editor uses a deep blue-gray background, soft neutral panels, 1 px translucent borders, 10–6 px corner radii, and low-saturation cyan for selection and focus. Glow is limited to selection, successful save, and successful recovery; transitions remain restrained at 120–20 ms.

Use the local system Chinese font stack, local Lucide icons, and bundled static assets. Do not use pervasive `backdrop-filter`, gradients, remote fonts, or remote assets. The editor appearance is fixed; future visitor themes apply only to Player output.
